# 强哥远程 0.3.0-beta.16 真机验收

这是一套统一验收包。请让两台 Windows 电脑使用同一次构建，Android 同时安装这次构建的启动器与配对伴侣。可以一次测完，也可以分几次记录。

## 安装与开测

1. 在本次 GitHub Actions 运行页的 **Artifacts** 下载 `windows-installers`、`android-apk`，需要自行部署激活服务时再下载 `activation-server`。
2. Windows 先从托盘退出旧版。普通控制端使用 `LULU-Remote-Setup-0.3.0-beta.16.exe`。已有通用版的被控机也可用同一安装包覆盖，安装后在「让别人连接我」开启远程控制。专用被控机使用 `LULU-Host-Setup-0.3.0-beta.16.exe`。记录安装结果和任何失败提示。主机安装器在组件准备失败时会停止并显示出错步骤。若提示需要重启 Windows，重启后再运行安装器。便携版需要完整解压。
3. Android 安装 `LULU-Remote-release.apk` 和 `LULU-Pairing-Worker-release.apk`。从旧调试版升级时，先记录设备地址等配置，再卸载旧的两款强哥远程 APK，重新安装。卸载会清除旧应用的本地状态和配对凭据。Moonlight 单独保留。
4. 验收构建使用组网内的预览激活服务。电脑和手机先加入同一组网，每台需要激活的设备使用各自的一次性验收密钥。不要在截图、日志或反馈里附上密钥、管理密码、协作码或完整机器指纹。
5. 从控制端设备卡用保存的地址连接一次。Windows 首次配对应直接打开相应的 Moonlight PIN 流程。被控端同意配对后测试画面和键鼠。安卓首次流媒体测试前先记录 Moonlight 的配对状态。

## 逐项验收

| 项目 | 怎么测 | 通过标准或要记录的现象 |
|---|---|---|
| 首次连接、组件准备 | 用已经装有 Moonlight 的 Windows 测一遍，再在一台干净 Windows 测一遍 | 已安装的能识别，缺组件时由应用引导准备。设备卡用已保存的地址即可连接。取消 UAC 或断开下载网络时有明确提示 |
| F00 配对伴侣 | Windows 按原步骤验证。Android 在设备卡点「连接 Moonlight」→「测试强哥远程配对伴侣」，记录主端与伴侣交接 | 显示 PIN、返回配对结果，重启后读回状态。Android 串流使用 Moonlight 自己的配对，见下方 |
| F01 隐私屏 | 被控端配置扩展双屏，依次用黑屏和自定义图片。只留托盘，再开始串流。再试一次在预览开着时开始串流。测试快捷键、结束串流及无效图片 | 被控物理屏都遮住，本地输入受阻。控制端看到真实桌面且能操作。`Ctrl+Alt+P` 可退出，断开后撤掉遮罩，无效图片回退黑屏。开始串流时预览会切换到实际遮罩 |
| F02 自动锁屏 | 开关分别设为开和关，进行一次串流再退出。再检查刚登录但从未连接的情形 | 开时结束后约 3 秒锁屏，关时留在桌面，未连接过不会锁屏 |
| F03 在线激活 | 测空白、错误密钥、同码在第二台设备使用、服务器地址填错、断网重启、服务端停机及吊销复核 | 新安装先进入激活页，错误分类明确，激活后可离线启动，吊销且复核成功才停用。复核有间隔，可用独立验收数据按服务端说明操作 |
| F04 文件传输 | 开启文件接收。从设备卡在组网内发送一个小文件和一个约 100 MB 的文件，中途持续操作串流。关闭接收后再发，也在传输途中关闭一次 | 进度可见，文件可打开且哈希一致，串流不中断，禁用后发送失败并提示检查接收开关 |
| F05 连接记录 | 连接、断开，打开「连接记录」，按日期筛选并导出 | 新记录和时长正确，文本可打开。配对请求过期或提交失败时核对已记录的失败环节。单次串流有明确 Sunshine 日志时，核对连接时间和结束时间。若测试机出现 Sunshine 启动失败或网络超时，核对记录里的原因。如果 Sunshine 的网络超时事件含有可核对的 Tailscale 节点，检查记录里的设备名。其余无法确认身份的串流显示「未识别控制端」 |
| F06 电源 | 回到设备菜单，在专门的验收主机上先取消确认，再测注销、重启、关机 | 取消时不执行。重启后 Windows 登录并确认 Sunshine 与托盘恢复，再连接。关机只在可以本地重新启动的电脑上测试 |
| F07 远程开机 | 两端连同一局域网，被控端接有线网线并在 BIOS 与 Windows 网卡允许网络唤醒。编辑设备保存有线网卡 MAC，再关机并点「开机」 | 两分钟内 Sunshine 上线后可连接，失败后有超时提示。跨网再按下面的步骤测试转发 |
| F08 分组和备注 | 给两台电脑设不同分组和备注，关闭重开，并让一台离线 | 分组和备注保留，离线卡片仍在且标题置灰 |
| F09 被控屏幕 | 被控端设扩展桌面，在两屏各放一个不同窗口。控制端从设备菜单点「选择被控屏幕」，用屏幕 2 连接。保持串流打开，再从同一菜单切到屏幕 1。在 Moonlight 中也可按 `Ctrl+Alt+Shift+F2` | 两个屏幕的画面与键鼠均可用，切换时连接保持。编号以 Sunshine 枚举顺序为准，目前每次捕获一块屏幕 |
| F10 文本剪贴板 | 被控端开启共享和「串流期间自动同步文本」。在 Windows 控制端启动串流，再从设备菜单打开「文本剪贴板」，输入协作码并点「本次串流自动同步」。分别在两端复制中文和带换行的测试文字，然后在另一端粘贴。最后断开串流并再次复制 | 两边能粘贴出原文。启动时两端原有剪贴板保持原样，断开后停止同步。单次上限 64 KiB。Android 可用手动收发 |
| F11 远程命令 | 在被控机开启「允许远程命令」。控制端在设备菜单选「远程命令」，输入协作码并执行 `hostname`。关闭被控端开关后重试 | 命令输出和本机一致，退出码为 0，关闭后拒绝。另可在被控端配置一个已知 EXE 和每行一个固定参数，再验证控制端的「被控端预设命令」回显 |
| F12 硬件信息 | 被控端开启共享，从控制端设备菜单查看「硬件信息」，对照任务管理器、系统盘属性、Windows 设置 | CPU、内存、系统盘与系统版本匹配，关闭后拒绝 |

## 跨网远程开机

1. 让一台常开 Windows 与目标电脑留在同一局域网。两台机器和控制端加入同一组网。
2. 在常开电脑打开「让别人连接我」的管理区域，登记目标电脑的有线网卡 MAC，点「开启唤醒转发」并复制转发协作码。
3. 控制端切到另一网络。编辑目标设备，填入它的有线网卡 MAC 和常开电脑的组网 IPv4。目标关机后点设备卡片的「开机」，输入转发协作码，记录 Sunshine 上线耗时。
4. 在转发电脑移除这个 MAC 或关闭唤醒转发。再次点击「开机」，确认请求被拒绝。最后清空控制端的转发地址，回同一局域网检查直接唤醒。

## 阶段 4 真机记录

- **Android 首次配对与直连**。用 Moonlight 尚未配对的实验主机，在强哥远程点「连接 Moonlight」→「复制地址并打开 Moonlight」。在 Moonlight 点「+」，粘贴地址，按提示提交 PIN，然后打开 Desktop 并验证画面和输入。退出串流后再从强哥远程点「已在 Moonlight 配对，尝试直连」。分别记录两次是否进入可操作画面。快捷入口失败时，可直接在 Moonlight 主机列表里选择电脑。Moonlight v12.2 的直接 Game Activity 为内部入口，验收版调用它的公开快捷入口和主界面。
- **无显示器与锁屏**。对能就地恢复的被控机，分别在拔除显示器、连接显示器但锁定 Windows、使用隐私屏三种条件下建立串流。记录黑屏、桌面、锁屏画面及键鼠响应。
- **重启恢复**。从设备菜单重启主机，记录 `SunshineService` 的运行状态。登录 Windows 后确认配对提醒托盘恢复。记录能否重连与耗时。主机版与通用版应分别验证所用的托盘自启设置。
- **记录格式**。每项记录日期、构建号、设备和系统、通过或失败、复现步骤与不含秘密的截图。正式发布与进度表勾选以这些结果为依据。
