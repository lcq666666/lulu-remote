# LULU Remote 开发计划与进度

仓库 `lcq666666/lulu-remote`，基线为 `main` 上的 `b39e9d3`（`v0.2.1`）。依据为用户已审核通过的 PRD v1.0（`lulu-remote-prd.md`）。

## 执行规则

- 顺序为阶段 0 → 1 → 2 → 3 → 4。一次推进一个阶段，汇报后等用户确认。阶段 2、3 的各功能项也按计划逐项汇报、等确认。
- 每项同时满足四个条件才打勾：实现完成、本地 `flutter analyze` 无问题、本地 `flutter test` 全部通过（新功能含新增测试）、该项规定的验收通过。把本文件中的勾与对应改动一起提交和推送。
- 每阶段完成后推送到 `main`，确认 GitHub Actions 全绿，再打标签发 Release，至少包含 Windows 通用安装器、Windows 主机安装器和 Android 调试 APK（阶段 4 改为发布签名）。汇报改动、提交 SHA、CI 运行号、测试结果和下一阶段。
- 遇到不确定的细节按计划与 PRD 的字面要求取舍，并在汇报时说明。版本以合入时 `main` 的最新版本为准，按发布阶段递增 minor（阶段 2 按 `v0.3.x`），同步安装器和 `installer/VERSIONS.md`。
- Sunshine 和 Moonlight 保持原样。`launcher/lib/pairing/` 仅可按 F00 明确要求拆分。密码、证书、密钥和激活令牌使用系统安全存储，禁止写入 SharedPreferences、JSON 文件、日志和仓库。
- PRD 第 6 节排除六项功能：观看模式、白板标注、屏幕墙、语音通话、远程打印、手机被控。

### F01 隐私屏（三档）

- [ ] 按隐私屏与自动锁屏设计的改 1 实现。新增 `launcher/lib/services/privacy_screen_service.dart`，管理显示、隐藏和会话状态。SharedPreferences 键为 `lulu_privacy_mode`（`off` / `black` / `image`，默认 `off`）和 `lulu_privacy_image`（可空本地路径）。
- [ ] 扩展 `launcher/windows/runner/flutter_window.cpp` 已有的 `lulu/host_tray` 通道，增加 `showPrivacyScreen` / `hidePrivacyScreen`。用无边框置顶窗口覆盖全部物理显示器；黑屏档纯黑，图片档铺满，图片加载失败退回黑屏。遮罩拦截本地输入，用 `Ctrl+Alt+P` 退出，保持远端画面与操作正常。
- [ ] 在 HostTray 的 2 秒轮询中检测会话。优先核实并使用 Sunshine 提供的会话状态，缺失时检测 47984 / 48010 的已建立 TCP 连接。会话开始时按设置显示，结束时隐藏，检测失败时不触发遮罩、不报错。
- [ ] 在「让别人连接我」的管理卡片加入三档、JPG / PNG 图片选择、低于 1920×1080 的建议尺寸提示，以及「立即预览」「关闭预览」按钮。串流期间改设置从下次连接生效，并在设置项旁说明。
- [ ] 测试三档读写及模拟会话的显示与隐藏状态转换。真机验收覆盖副屏黑屏和远端操作、图片显示、热键退出、断开后恢复、坏图片回退、设置下次生效及托盘模式。

**当前进度（未验收，不打勾）**：开发分支增加了三档设置、JPG / PNG 选择和 Windows 本机预览；预览在 12 秒后自动退出，快捷键不可用时仍可用窗口按钮关闭。已用 Windows 原生探针验证双屏虚拟桌面窗口尺寸、PNG 加载、坏图回退、关闭消息和预览超时。双端真实串流还未验收，尚未开启自动遮罩。

Sunshine `v2026.914.233613` 的管理页客户端列表是配对列表，`/serverinfo` 的忙碌标志表示应用仍在运行，都不能代表串流会话。该版本 RTSP / HTTPS 建连不会维持整个串流，预览分支改用 `sunshine.exe` 拥有的 RTSP 监听端口与其对应的三个 UDP 串流端口作为候选信号；已用本机模拟端口验证空闲、启动和结束，尚需真串流核对启停时间。这里的端口信号表示串流传输已分配，不代表远端已成功看到画面；检测失败保留为未知，不视为会话结束。

自动遮罩的剩余条件：确认当前 Sunshine 捕获后端忽略遮罩，并且本地键鼠被挡时远程键鼠仍可用。不能用窗口抢焦点或直接屏蔽所有输入代替验收；当前 Sunshine 也支持通过虚拟设备注入输入，不能仅凭输入事件是否标记为注入来区分远端与本地。

### F03 在线激活（一机一密钥）

- [ ] 按在线激活详细设计建立 `server/`。优先 Go 单可执行文件与 SQLite，备选 Python FastAPI 与 SQLite。服务仅监听配置的组网地址。`server/README.md` 说明启动、开机自启、数据库位置与备份方式。
- [ ] 实现 `POST /v1/activate`（事务内标记已用、绑定指纹并签发令牌，错误分别为 404 密钥不存在、409 已使用、400 机器码格式问题）、`GET /v1/status` 健康检查、`POST /v1/validate` 吊销复核。密钥格式为 `LULU-XXXX-XXXX-XXXX-XXXX`，排除 `0/O` 与 `1/I`，最后一位为校验位。
- [ ] 令牌用 Ed25519 签名，包含机器指纹哈希、密钥编号、签发时间。私钥保存在服务器，客户端内置公钥。管理命令包含 `keys generate --count 20 --note 实验室`、`keys list`、`keys revoke <密钥>`、`devices list`、`devices revoke <机器指纹>`。
- [ ] 新增 `machine_code_service.dart`。来源为主板序列号、硬盘序列号、Windows MachineGuid，计算 SHA-256，取前 16 位分组显示。三项中两项相同视为同一设备。单项读取失败可空，全部失败时明确报错。
- [ ] 新增 `activation_service.dart`、`activation_screen.dart`。启动时从 SecureStore 读令牌，核验签名和机器指纹。通过后进入 HomeScreen 并启动托盘伴侣。激活页含可复制机器码、密钥输入、可编辑的默认组网服务器地址（服务器地址存 SharedPreferences）和激活按钮，并说明激活后可离线使用。
- [ ] 区分服务器连不上、密钥不正确、密钥已使用、本机硬件变化四种文案。激活后令牌存 SecureStore，设置页显示「已激活 · 机器码后 4 位」及重新激活入口。联网时每周最多复核一次，只有服务器确认吊销才清理令牌并返回激活页提示停用。
- [ ] 新增密钥校验、指纹容差、签名校验、四种错误文案测试，以及同密钥并发激活仅一次成功的服务端测试。真机验证全新安装、错密钥、第二台重复使用、断网重启、服务器停机、吊销后复核停用、错误服务器地址。
- [ ] 发布时附上带版本号的服务器与 keygen 工具，Release 说明写清启动及生成密钥的方法。
