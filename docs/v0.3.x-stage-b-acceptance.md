# 强哥远程 v0.3.x · 阶段 B 真机验收

候选版本：`0.3.1-rc.1+47`，基于阶段 A 独立候选 `7b3c08c`。本页结果均待用户填写，不用自动测试替代真机。A 的 F01–F03 和三项旧版遗留验证仍按[阶段 A 验收表](v0.3.0-stage-a-acceptance.md)逐项完成；不要拿 B 的结果给 A 的独立发版提交打勾。

## 开测准备

- 用两台有测试权限的 Windows，另备 Android；跨网 WOL 还需目标同一局域网里的一台常开 Windows 做转发。在目标旁安排可接触键盘和电源的人。
- Windows 直接运行本次候选安装器。Android 同时安装同一构建、签名一致的启动器和独立配对伴侣 APK；调试签名仅用于本次自测，不外发。记录安装包版本、提交、系统和组网方式。
- 两端先完成首次授权配对。B 的文件接收、远程电源、唤醒转发各有单独的码，不用配对 PIN、管理密码或激活密钥代替。结果表、截图和日志里不要贴这些码。
- 文件、远程电源、唤醒转发经同一 TCP 47995，仅绑定识别到的组网 IPv4。启用了对应功能却连不上时，先确认主机托盘正在运行、两台机在同一组网，再检查组网 ACL 和 Windows 防火墙对该程序和组网的入站规则。不要关闭防火墙或向公网开放端口。记下干净安装能否直连、有无防火墙提示。
- F06/F07 会真的注销、关机或唤醒。先保存文件，只用验收机，不用正在跑实验或承载激活服务的电脑。

| 项目 | 怎么验 | 通过标准 | 结果 |
| --- | --- | --- | --- |
| F04 · 默认目录、拖放、100 MB | 主机开启「文件接收」，确认默认目录为桌面「LULU 接收」。控制端从设备菜单把 100 MB 无敏感信息的文件拖入发送窗口。再次从文件选择器发送，另选一个接收目录重复。 | 显示进度、速度和成功提示；在目标能打开，源与目标的 SHA-256 一致；选目录后保存到新目录。 | 待验 |
| F04 · 串流中传输与停用 | 串流中切回强哥远程发送文件，确认串流画面和输入仍能用。另测错误接收码和主机关闭「文件接收」，关闭后再发；有条件再在上传过程中关闭。Windows 和 Android 的文件选择各试一次。 | 串流不卡死、不被切断；错误码和关闭接收时均不保存文件，控制端有明确提示；中途关闭后无残留半成品。 | 待验 |
| F05 · 串流与配对记录 | 主机打开「连接记录」的开关，做一次配对、一次串流后正常断开，另试一次可复现的失败。打开本机「连接记录」核对数量、日期、开始/结束和时长；组网能验证控制端名的路径核对名字。 | 每次增加对应记录，不重复。时间与实际吻合。可识别的失败显示原因；无法验证名字显示「未识别控制端」，不冒认。 | 待验 |
| F05 · 日期、导出与关闭 | 打开最近 30 条和按日期筛选，导出 TXT 后用记事本打开。关闭「在本机记录连接」，重新连接再刷新。 | 导出中文可读，不含密码、码、文件内容或键鼠记录；新的连接不再记录，旧记录仍可查看。 | 待验 |
| F06 · 二次确认与停用 | 串流中在设备菜单选「重启」，先点取消；再关闭主机远程电源并提交请求。 | 提示操作会断开连接；取消或关闭功能时，被控电脑不执行任何电源动作。 | 待验 |
| F06 · 真正注销、重启、关机 | 只在验收机开启远程电源。依次实测注销、重启、关机（每次都确认并先保存数据）。重启后查看 Sunshine 是否自动启动；验收用户正常登录后检查托盘是否自动出现、无需手动开应用且可重连。 | 注销仅结束 Windows 会话，重启后能重新连，关机真正完成。记录 Sunshine 启动和托盘启动，不把登录前与登录后混为一谈。 | 待验 |
| F07 · 同网直唤醒 | 目标接有线网卡并在 BIOS/UEFI 与网卡设置开启 WOL。保存该网卡 MAC，不填转发地址。正常关机后，从同一局域网的控制端点「开机」。 | 两分钟内 Sunshine 上线、卡片显示在线并可连接。 | 待验 |
| F07 · 跨网转发、关停和超时 | 同 LAN 常开 Windows 登记目标 MAC 并开启转发，控制端跨网填转发电脑的组网 IPv4 和转发码。试正确码、错误码、未登记 MAC、关闭转发；再在本地可恢复的目标关闭 WOL 或让目标明确不能接收唤醒包。 | 授权转发能唤醒并在两分钟内上线。错误码、未登记或关闭时拒绝；超时时结束等待并提示检查有线网卡、BIOS/UEFI 和局域网。清掉设备的 MAC 与转发地址后不再显示「开机」。 | 待验 |
| F08 · 分组与备注持久化 | 把两台电脑分入不同组，至少改一个备注名，留一台离线。完全退出应用再打开。清空一台的分组和备注，再退出重启。 | 两组和备注能恢复；离线设备淡显但不消失。清空后回到未分组、显示原名，配对信息仍在。 | 待验 |
